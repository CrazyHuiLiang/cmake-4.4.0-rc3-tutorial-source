# CMake 教程

## 简介

CMake 教程提供了一份循序渐进的指南，涵盖了 CMake 有助于解决的常见构建系统问题。在一个示例项目中观察各个主题如何协同工作，会非常有帮助。

## 步骤

教程的源代码示例可从[此压缩包](../../_downloads/0a258b4d00376f5addcda21ec90aeac3/cmake-4.4.0-rc3-tutorial-source.zip)获取。每一步都有各自的子目录，其中包含可作为起点的代码。教程示例是渐进式的，因此每一步都提供了上一步的完整解决方案。
